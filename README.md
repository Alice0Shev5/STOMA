# STOMA Mobile
## Концепция продукта
*STOMA Mobile – мобильное приложение стоматологической клиники STOMA (г. Газалкент, Узбекистан). 
Приложение переносит ключевые сервисы клиники в смартфон пациента: онлайн-запись, личный кабинет, историю лечения, снимки, оплату и связь с клиникой. 
Оно станет персональным помощником пациента на всём пути лечения – от первой записи до контроля плановых визитов.*
