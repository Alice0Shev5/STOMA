# STOMA Mobile

Мобильное приложение стоматологической клиники **STOMA** (г. Газалкент, Узбекистан).

Приложение переносит ключевые сервисы клиники в смартфон пациента: онлайн-запись, выбор врача, просмотр расписания и управление своими записями.

---

## 📱 Экраны

| # | Экран                 | Что делает |
|---|-----------------------|-----------|
| 1 | **Выбор услуги**      | Список услуг клиники с поиском и фильтром по категориям (лечение, гигиена, имплантация, ортодонтия, протезирование) |
| 2 | **Выбор врача**       | Специалисты, отфильтрованные по выбранной услуге. Карточка с фото, специализацией, стажем и рейтингом |
| 3 | **Календарь и слоты** | Лента из 14 дней, слоты по 30 минут (9:00–19:00), разделение на «Утро / День / Вечер», bottom sheet с деталями перед подтверждением |
| 4 | **Мои записи**        | Список оформленных записей с возможностью отмены. Данные хранятся локально в Room |

---

## 🚀 Точка входа в приложение

**`MainActivity`** — единственная Activity, объявленная как `LAUNCHER` в `AndroidManifest.xml`.
